# plan.json / timing.json (what the engine plays)

## plan.json

```jsonc
{
  "title": "Fish Can Fly",                 // 2–4 words; shown on vertical cut / used as fallback
  "outro": "Salmon in the river, DNA in the air.",   // end-card line; *word* → italic accent
  "images": { "img1": "/project/source/images/img1.png" },   // optional README pictures
  "beats": [
    {
      "scene": "1 River",                  // consecutive beats with the same name = one scene (one canvas)
      "narration": "Salmon are swimming up a river,",
      "transition": "cut",                 // only on a scene's first beat: slide | push | zoom | cut | "" (auto)
      "elements": [                        // NEW elements this beat adds (they persist for the rest of the scene)
        { "id": "title", "kind": "heading", "at": "", "x": 2.08, "y": 2.1, "w": 7.38, "h": 1.58, "text": "Fish can *fly*" },
        { "id": "fish", "kind": "chip", "at": "salmon", "x": 2.08, "y": 4.17, "w": 4.9, "h": 0.87, "text": "river: coho, chinook", "tone": "accent" },
        { "id": "up", "kind": "arrow", "at": "sampler", "x": 0, "y": 0, "w": 0, "h": 0, "from": "water", "to": "air", "label": "", "dashed": true, "flow": false }
      ],
      "actions": [ { "do": "highlight", "at": "sampler", "target": ["air"] } ]
    }
  ]
}
```

- Canvas: **16 × 9 units, 1 unit = 120 px** (1920 × 1080). Keep content inside x∈[1,15], y∈[1.2,7.4]:
  the top-left pill sits at ~y 0.4–0.8 and captions occupy the bottom ~1.4 units.
- `at` = cue word, matched (normalized: lower-case, letters/digits only) against the beat's spoken words;
  exact match first, then a shared stem > 3 chars. Empty = beat start.
- Element fields per kind: see `shot-language.md`. Arrows keep 0 coordinates (routed automatically).
- Editing coordinates by hand is OK for nudges (move/resize an existing element). For anything new, use a design + compile.

## timing.json (generated by `voice`, don't hand-edit)

```jsonc
{ "DURATION": 84.9,          // film length (speech end + ~3.6 s for the end card)
  "SPEECH_END": 80.86,
  "beats": [ { "start": 0.4, "end": 2.5, "words": [ { "w": "salmon", "s": 0.4, "e": 0.8 }, … ] } ],
  "narration": [ "…beat 0 text…", … ] }   // what was voiced; `check` compares it to plan.json
```

`words` must have one entry per whitespace-separated token of the narration (captions index by position).
`voices.json` = `[{ "start": 0.4 }]`: where voice.mp3 begins on the film clock.

## End card & chrome

The end card appears at `min(DURATION − 2.4, SPEECH_END + 0.5)`: outro line + link (+ signoff). The thin
purple progress rail runs along the bottom for the whole film. Captions are burned in (karaoke-style:
spoken words light up). Toggle with `project.json → captions`.
